# Smart Accounts
### Simple • Fast • Open Source

تطبيق بسيط وعملي يساعدك تسجل حساباتك وعملياتك الحسابية اليومية بسهولة وتنظيم.  
سواء بتحسب مصاريف، أرباح، ديون، أو أي أرقام مهمة — التطبيق بيخزن كل حاجة بشكل مرتب وسريع.

</div>

---

## ✨ المميزات

- تسجيل العمليات الحسابية بسهولة
- حفظ النتائج والملاحظات تلقائي
- واجهة بسيطة ونظيفة
- سرعة وأداء خفيف
- تنظيم الحسابات بطريقة سهلة
- مناسب للدراسة والشغل والحياة اليومية
- Open Source بالكامل

---

## 📱 فكرة التطبيق

بدل ما تفضل تكتب أرقامك في النوت أو تضيع عملياتك الحسابية، التطبيق بيوفرلك مكان بسيط تحتفظ فيه بكل حساباتك وترجع لها في أي وقت.
