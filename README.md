## ✨ المميزات الرئيسية (Core Features)

### 1️⃣ لوحة التحكم الفاخرة (Obsidian Luxury Dashboard)
* **استعراض ذكي للميزانية:** نظرة شاملة وفورية على الرصيد الإجمالي، المصروفات، والمدخولات مع تصميم بطاقات تفاعلية فاخرة.
* **إحصائيات متقدمة:** رسوم بيانية ملونة وسلسة لاستعراض توزيع المصروفات حسب التصنيفات المختلفة (أكل، تسوق، فواتير، صحة، ترفيه، وغيرها).

### 2️⃣ إدارة البطاقات الرقمية المميزة (Premium Digital Cards)
* **محاكاة البطاقات الحقيقية:** يتيح لك التطبيق محاكاة بطاقات الدفع البنكية الخاصة بك (مثل بطاقات المشتريات، بطاقة الراتب الخارجي) بشكل بصري غاية في الأناقة وبشاشات تفاعلية تعرض آخر العمليات المرتبطة بكل بطاقة على حدة.

### 3️⃣ المعاملات الدورية ومحرك التأكيد التلقائي (Auto-Confirm & Recurring Transactions)
* **جدولة المصاريف والرواتب الروتينية:** أضف معاملاتك التي تتكرر باستمرار (مثل إيجار المنزل، فاتورة الإنترنت، أو الراتب الشهري).
* **التأكيد بلمسة واحدة:** نظام ذكي ينبهك في موعد المعاملة ويسمح لك بتأكيد إضافتها بحركة واحدة داخل لوحة التحكم.

### 4️⃣ التنبيهات والمذكرات الذكية (Smart Reminders & Alarms)
* **جدولة المستحقات:** لن تقلق أبداً مجدداً بشأن فواتيرك المتأخرة، حيث يدعم التطبيق تسجيل مذكرات وتنبيهات مخصصة تظهر كإشارات واضحة لتذكيرك قبل حلول موعد الدفع.

### 5️⃣ الأداء الخارق والخصوصية المطلقة (Robust & Private)
* **قاعدة بيانات Room المحلية:** جميع بياناتك المالية، معاملاتك، وبطاقاتك يتم تخزينها وتشفيرها محلياً على جهازك؛ لا يوجد أي خادم وسيط يقرأ بياناتك، خصوصيتك هي غايتنا الأولى.
* **العمل بدون إنترنت (100% Offline):** التطبيق يعمل بكفاءة تامة وسرعة استثنائية دون الحاجة لوجود اتصال بالإنترنت.

## 🎨 الهوية البصرية وأيقونة التطبيق الفاخرة (App Icon Description)
تم تصميم أيقونة التطبيق الحالية يدوياً وبأسلوب **Adaptive Icon** الحديث المتوافق مع معايير Material Design 3:
* **الخلفية (`ic_launcher_background`):** لون أسود داكن من حجر الأوبسيديان الفاخر `#0A0A0C`.
* **العنصر الأمامي (`ic_launcher_foreground`):** رمز المحفظة والبطاقة الذكية مطلياً بذهب عيار 24 قيراط مكللاً بنجم صاعد باللون الأخضر الزمردي الأنيق `#10B981` للإشارة إلى تزايد وتنامي مدخراتك المالية.

## 🛠️ التقنيات المستخدمة (Technical Stack)

* **لغة البرمجة (Language):** Kotlin 1.9.24 (The absolute Standard).
* **بناء الواجهات (UI Framework):** Jetpack Compose مع ميزات وتأثيرات Material 3 الراقية.
* **البناء الهيكلي والتنقل (Navigation):** Jetpack Compose Navigation ذو المرجعية الآمنة بالأنماط الصارمة.
* **إدارة البيانات والتشغيل (MVI / MVVM Pattern):** هندسة ViewModel مقترنة بـ StateFlow وجامعات الحالة التفاعلية.
* **قاعدة البيانات (Local Database):** SQLite / Room Database مدمج مع معالج الرموز KSP.
* **مستوى أمان واجهة أندرويد (SDK Target):** Android SDK 14 (API Level 34).

## 🚀 كيفية تشغيل وتثبيت التطبيق (How It Operates & Runs)

لتشغيل التطبيق والبدء في تطويره أو تجربته على جهازك الشخصي أو محاكي أندرويد، اتبع الخطوات البسيطة التالية:

### المتطلبات المسبقة (Prerequisites)
1. تثبيت **Android Studio (Ladybug 2024.2.1)** أو إصدار أحدث.
2. وجود حزمة تطوير جافا **JDK 17** مثبتة ومعرفة في البيئة.
3. تفعيل وضع التطوير وتصحيح أخطاء الـ USB (USB Debugging) في هاتفك الذكي وتوصيله بالجهاز.

### خطوات التشغيل والتحميل (Compilation Steps)

1. **تحميل شيفرة المصدر (Clone Repository):**
   ```bash
   git clone https://github.com/your-username/hisabati-finance.git
   cd hisabati-finance
   ```

2. **بناء المشروع عبر موجه الأوامر (Command Line Build):**
   يمكنك استخدام أداة Gradle المرفقة لبناء حزمة الـ APK مباشرة:
   ```bash
   # لأجهزة الماك واللينكس
   ./gradlew assembleDebug

   # لأجهزة الويندوز
   gradlew assembleDebug
   ```

3. **التثبيت المباشر على الهاتف (Deploying to Device):**
   يمكنك استيراد المشروع في بيئة Android Studio ثم النقر على زر **Run 🟢 (Shift + F10)** لتلقائياً بناء وتنزيل التطبيق في هاتفك.

## 🛡️ الخصوصية والأمان (Security & Privacy First)
يهتم تطبيق **حساباتي** بأمنك الشخصي والمالي بأقصى جدية:
* لا نجمع أي بيانات تتبع أو معاملات مبيعات.
* لا توجد واجهات تطبيق خارجية ترسل لها معلوماتك بدون إذنك.
* الأرقام المكتوبة في تفاصيل البطاقات هي أرقام محاكاة محلية ولا يتم ربطها بنظام الدفع الفعلي لضمان سلامة حساباتك البنكية.
